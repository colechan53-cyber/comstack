# S32K144 AUTOSAR 工程

## 项目简介

本工程基于 NXP S32K1xx 系列微控制器和 IAR Embedded Workbench，使用
Vector MICROSAR / DaVinci Configurator 生成并集成 AUTOSAR Classic
Platform 软件栈，目标板为 S32K144。

工程当前用于学习、验证和扩展 S32K144 上的 AUTOSAR 基础软件功能，包含
应用层、BSW、MCAL 配置、RTE 生成代码以及 IAR 工程文件。

## 目录说明

## 开发环境

- MCU：NXP S32K144
- IDE：IAR Embedded Workbench
- AUTOSAR 平台：Vector MICROSAR Classic
- 配置工具：DaVinci Configurator / 工程所配套的 tresos 资源
- 调试及报文分析：可结合 J-Link、CAN 工具和 TSMaster 使用

具体工具版本、编译器选项和硬件连接方式应以当前工程文件及本地开发环境
为准。

## 基本使用流程

1. 使用 IAR 打开根目录下的 `IarStartApp.eww` 或对应的 `.ewp` 工程文件。
2. 检查工程使用的设备、编译器、链接文件和调试器配置是否与本地环境一致。
3. 在修改 ECU 或 BSW 配置后，按照项目配置流程重新生成 RTE 和相关 BSW
   代码。
4. 编译工程并下载到 S32K144 目标板。
5. 结合调试器、CAN 分析工具或 TSMaster 验证运行结果。

`Appl/GenData/` 下的内容主要由配置工具生成。除非明确需要手工修复生成
结果，否则应优先修改配置源文件后重新生成，避免直接编辑生成文件。

## 当前状态

工程已经包含 S32K144 的 IAR 工程、AUTOSAR 基础软件集成内容、MCAL 配置、
RTE 生成代码以及用于调试和验证的相关文件。当前重点是保持现有工程能够
稳定编译、下载和运行，并逐步补齐 SIP 中缺失的功能模块。

## 下一步开发计划

下一阶段将主要开发 **SIP 包中不存在的 IpduM 部分**。

计划重点包括：

- 梳理当前 SIP/MICROSAR 中 IpduM 的缺失范围和对外接口；
- 根据 AUTOSAR 规范设计 IpduM 的数据结构、初始化流程和运行时处理流程；
- 衔接 IpduM 与 PduR、CanIf、Com 等相关模块之间的调用关系；
- 完善 I-PDU 组、信号 PDU 映射以及发送和接收路径；
- 结合现有 CAN 配置和 RTE 环境进行集成验证；
- 为关键路径补充调试日志、边界条件处理和回归测试。

在 IpduM 开发过程中，应尽量遵循工程现有的模块分层、命名规范、内存映射
方式和错误处理方式，并明确区分手写代码与配置工具生成代码。
